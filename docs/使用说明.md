# 给同事：如何使用 Paper Reader

这是一个装在自己电脑上的论文阅读工具。打开后是网页，论文和聊天记录都留在本机，不会上传到我们的服务器。

日常使用只需：**双击启动 → 浏览器自动打开 → 导入论文**。
第一次使用前，需要先装好两样软件，并在设置页填入模型信息。

## 1. 第一次使用前准备

请按顺序做完下面三步。装好后一般不用再装。

### 第一步：安装 Node.js

1. 打开 [https://nodejs.org](https://nodejs.org)
2. 下载标有 **LTS** 的安装包（Mac 选 macOS Installer，Windows 选 Windows Installer）
3. 双击安装，全部选默认选项即可
4. 装完后**重启一次电脑**（或至少关掉并重新打开终端）

### 第二步：安装并登录 Pi

论文问答、概括、精读会调用你电脑上的 **Pi**。翻译不走 Pi，走下一步设置里的接口。

**Mac：**

1. 打开「终端」（启动台里搜 Terminal）
2. 复制下面这一行，粘贴后按回车：

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

3. 安装结束后，在终端输入 `pi` 并回车
4. 按提示执行 `/login`，登录你的模型账号或填入 API Key
5. 用 `/model` 选一个日常使用的模型，按 `Ctrl+S` 存成默认

**Windows：** 用 PowerShell 运行 Pi 官网给出的安装命令，然后同样执行 `pi` → `/login`。

如果这一步跳过，阅读和导入论文仍可用，但右侧「论文助手」无法回答。

### 第三步：拿到软件文件夹

请向分享者要整个项目文件夹（不要只拷里面某一个文件）。
放到自己电脑后记住位置，例如「文稿 / PaperReader」。

## 2. 启动

### Mac（推荐）

1. 打开项目里的 `scripts` 文件夹
2. 双击 `start.command`
3. 若弹出「无法打开，因为来自身份不明的开发者」：
   - 按住 Control 键再点一次 `start.command`
   - 选择「打开」
4. 第一次启动会自动安装依赖并打包页面，可能要等 1～2 分钟
5. 终端窗口请保持开着；浏览器应自动打开 [http://127.0.0.1:3080](http://127.0.0.1:3080)

关掉那个终端窗口 = 退出软件。下次再用，再双击一次即可，一般会快很多。

### Windows

1. 双击 `scripts\start.bat`
2. 同样保持黑色窗口不要关
3. 浏览器打开 [http://127.0.0.1:3080](http://127.0.0.1:3080)

### 如果双击没有反应

打开终端（Mac）或 PowerShell（Windows），进入项目文件夹后执行：

```bash
npm install
npm run build
npm start
```

然后手动打开 [http://127.0.0.1:3080](http://127.0.0.1:3080)。

## 3. 第一次打开后：填设置

左下角点 **「设置」**：

**翻译模型（必填，否则无法翻译选区）**

- Base URL：例如 `https://api.openai.com/v1`，或你常用的中转地址
- 模型名称：例如 `gpt-4o-mini`
- API Key：你的密钥。保存后不会再完整显示，留空表示保持原密钥

**论文阅读模型（走 Pi）**

- Pi 模型：可留空，表示用你在 `pi` 里保存的默认模型
- 思考强度：一般用 `medium`
- 下方三块提示词：概括全文、精读章节、解释图片，可按自己习惯改

点 **「保存设置」**，再点 **「返回阅读」**。

密钥只存在你这台电脑的本地配置里，不会进 Git，也不会出现在网页前端文件中。

## 4. 日常怎么用

1. 左侧 **导入 PDF**，或粘贴 arXiv 链接后点导入
2. 点一篇论文，中间上下滚动阅读
3. 在 PDF 上拖选文字 → 顶栏 **「翻译选区」**（翻译在中间下方单独显示，不进入右侧对话）
4. 需要截图时，先点顶栏 **「框选图片」**，框完即附加到下一句提问
5. 右侧输入问题，**Enter 发送**，**Ctrl+Enter 换行**
6. 「概括全文 / 精读当前章节 / 解释图片/表格」是快捷提问

**文件夹**

- 单击文件夹：展开或收起，并作为导入目标
- 右键文件夹：重命名、新建子文件夹、导入、删除（删除会连同里面的论文一起删掉）
- 右键论文：单独删除一篇

论文文件和翻译缓存保存在项目下的 `.runtime/` 目录。不要把这个目录发给别人，里面是你的论文和对话相关数据。

## 5. 常见问题

**网页打不开**
先看启动窗口是否还在。关掉后需要重新双击启动。确认地址是 `http://127.0.0.1:3080`，不要用 https。

**提示找不到 node / npm**
Node.js 没装好，或装完没有重启。回到第 1 步。

**PDF 打不开或很模糊**
用最新版本的 Chrome / Edge / Safari。不要用很旧的浏览器。

**翻译失败**
到设置页检查 Base URL、模型名和 API Key。保存后再试。

**右侧助手没有回复 / 提示 pi 启动失败**
本机没有安装 Pi，或尚未 `/login`。阅读本身不受影响。

**导入后标题是文件名**
工具会先认 arXiv 编号；认不到再让 Pi 读首页。Pi 不可用时仍会导入，标题先用文件名，并弹出原因。

**想换一台电脑用**
把整个项目文件夹拷过去（可以不拷 `node_modules`）。在新电脑重新做第 1、2 步，再双击启动。论文在 `.runtime/` 里，需要一并拷贝才会看到原来的库。

**如何退出**
关闭启动时弹出的终端窗口，再关掉浏览器标签即可。
